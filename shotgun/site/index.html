shotgun

Any coding agent picks up where the last one stopped.

Open in the Claude app Open in a terminal

Claude Code opens with the install line typed in. Press Enter to install shotgun.

If nothing opens, paste this line into Claude Code or Codex:

Install shotgun from https://github.com/adamalshoomary/shotgun.

Then

Open a new chat in your project folder and run this command. The agent asks you about the project, then writes four files.

/shotgun setup

Start every later session with this command:

/shotgun continue

Four files in your project

your-project/
├── AGENTS.md             the rules every agent follows
├── project-purpose.md    what you are building and for whom
├── current-state.md      what works now, and what just changed
└── improvement-plan.md   the task queue

You need Claude Code, Codex or another agent that reads Agent Skills. In Codex, type $shotgun.
